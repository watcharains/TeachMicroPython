[Ready] Click "Connect micro:bit" to pair over Web Bluetooth.
Why micro:bit connects (shows ✓) but ignores button presses:
  1. In MakeCode, click ⚙️ Project Settings and turn ON "No Pairing Required: Anyone can connect via Bluetooth", then re-download the .hex file to your micro:bit. (Without this, micro:bit shows the ✓ icon on connect but blocks all UART writes.)
  2. If you previously paired the micro:bit in macOS or Windows Bluetooth settings, click Forget / Remove Device in your OS Bluetooth settings so Web Bluetooth uses a clean GATT link.
